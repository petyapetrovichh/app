## Session log (backup)

At the end of every work session in this repo — when the task is finished or the user wraps up — write a short log to `docs/sessions/YYYY-MM-DD_<short-slug>.md` and commit it together with the work. Format:

- **Request:** what the user asked for (1–3 lines)
- **Done:** what was built or changed, key files
- **Decisions:** important choices and why
- **Open items:** what is left or blocked

Keep it short (under ~40 lines), in the language of the conversation. Never put API keys, tokens or passwords in it. If a log for today's session already exists, update it instead of creating a new one.
